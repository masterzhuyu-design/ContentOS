# 对外聊天简要说明

## 一句话版

这是一个可以自己掌控文件的轻量个人知识系统：能学习、问答、复习、沉淀和复用知识，也能做分享卡、搜索与创作；轻量化的是模型、索引、自动化和每轮加载量，不是核心功能。

## 直接复制版

我做了一套可本地保存、可持续升级的轻量个人知识系统。它可以把资料变成直接讲解、拆解问答和迁移问答，安排柔性复习计划，并把概念、模型、案例和本体关系收进知识库；以后学习、创作或解决问题时，还能按需复用这些旧资产。它也保留了分享卡、轻量搜索、内容创作和质量检查。

轻量化主要做在运行层：发行版没有捆绑本地大模型、Ollama、KnowledgeOS、向量数据库、账号登录或自动发布；每次只按任务加载最小规则，用文件指针和摘要减少重复上下文，修改内容时只应用用户确认差量，避免讨论过程污染原稿。知识正文仍保存在 Markdown/JSON 里，用户可以查看、迁移和继续升级。

## 使用前提

基础使用需要 Codex desktop 和 PowerShell；Git 建议安装，Obsidian 可选。发行包是空知识库，不包含制作者的私人资料、账号、历史记录或本地模型。

## 把 ZIP 交给 Codex 安装

上传 ZIP 后，可以把下面这句话一起发给 Codex：

> 请先检查这个 ContentOS Lite ZIP，把它安装到一个新文件夹，不要覆盖我的现有知识库；安装后运行自带验证，并告诉我安装路径、验证结果和下一步怎么开始使用。

Codex 可能会请求目标目录写入权限；只上传 ZIP 而不说明安装目标时，它通常只会把文件当作附件读取。
