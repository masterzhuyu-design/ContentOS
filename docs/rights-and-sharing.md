# 内容权利与分享

## 本仓库的双许可证

| 内容 | 许可证 |
|---|---|
| 代码、PowerShell 脚本、JSON Schema、机器可读配置 | MIT |
| 原创规则、模板和文档 | CC BY-SA 4.0 |

完整文本分别见根目录的 `LICENSE` 与 `LICENSE-DOCS.md`。对规则、模板或文档做公开改编时，需要署名、标注改动，并以 CC BY-SA 4.0 共享改编版本。

## 不随仓库授权的内容

- 使用者自己的笔记、草稿、学习历史和项目资料仍归使用者；
- 书课正文、平台内容、截图、图片、字体、第三方案例和模型权重按各自权利处理；
- 把第三方内容放进私人 vault，不会自动获得公开再分发权；
- 本仓库不包含作者的私人 vault、账号、Cookie、Token、Registry、checkpoint 或运行数据库。

## 生成分享卡或对外作品时

优先分享自己的理解、论证、案例和表达，不用长篇摘录替代原作。发布前检查来源、必要引用、隐私、素材授权和结论是否超出证据。

分享卡只是可交付正文，不自动触发图文渲染、平台登录或发布。外部发布始终需要对应适配器和当次授权。
