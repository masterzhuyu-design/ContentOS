# 内容权利与分享

## 默认边界

- 用户自己的笔记可以进入私人 vault；
- “可以私人学习”不自动等于“可以随发行包或公开内容再分发”；
- 书课、平台内容、截图、图片、字体和第三方案例默认不进入公共发行包；
- 分享卡优先转化成自己的理解、判断、案例和表达，不长篇替代原作。

## 分享卡

普通分享卡是正文型 detached export。它不自动创建图文、视频、平台草稿或发布动作。

分享前检查：

- 事实与来源；
- 是否保留过多独特表达或结构；
- 案例隐私；
- 引用长度和必要性；
- 是否说明改编与来源；
- 结论是否超出证据。

## 发行许可证

- 代码：MIT；
- 原创规则与文档：CC BY-NC-SA 4.0；
- 第三方对象：服从其各自许可证和授权，不因放入 vault 而改变。

需要商业使用、再许可或加入第三方资产时，应单独复核，不能只依赖本说明。
